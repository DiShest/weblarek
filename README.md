## Типы данных

### IProduct

Интерфейс товара.

``` ts
interface IProduct {
    id: string;
    description: string;
    image: string;
    title: string;
    category: string;
    price: number | null;
}
```

------------------------------------------------------------------------

### IProductsResponse

Тип ответа сервера с массивом товаров.

``` ts
interface IProductsResponse {
    total: number;
    items: IProduct[];
}
```

------------------------------------------------------------------------

### TPayment

Тип способа оплаты.

``` ts
type TPayment = 'card' | 'cash';
```

------------------------------------------------------------------------

### IBuyer

Интерфейс данных покупателя.

``` ts
interface IBuyer {
    payment: TPayment;
    address: string;
    email: string;
    phone: string;
}
```

------------------------------------------------------------------------

### IOrder

Интерфейс заказа.

``` ts
interface IOrder {
    items: string[];
    total: number;
    payment: TPayment;
    address: string;
    email: string;
    phone: string;
}
```

------------------------------------------------------------------------

### TOrderForm

Тип формы первого шага заказа.

``` ts
type TOrderForm = Pick<IOrder, 'payment' | 'address'>;
```

------------------------------------------------------------------------

### TContactsForm

Тип формы контактов покупателя.

``` ts
type TContactsForm = Pick<IOrder, 'email' | 'phone'>;
```

------------------------------------------------------------------------

### TFormErrors

Тип ошибок валидации формы.

``` ts
type TFormErrors = Partial<Record<keyof IBuyer, string>>;
```

------------------------------------------------------------------------

### IOrderResponse

Тип ответа сервера после оформления заказа.

``` ts
interface IOrderResponse {
    id: string;
    total: number;
}
```

## Классы моделей данных

### ProductsModel

Класс модели каталога товаров.

Отвечает за: - хранение массива товаров; - получение товара по id; -
хранение товара для предпросмотра.

#### Поля

``` ts
protected items: IProduct[];
protected preview: IProduct | null;
```

#### Методы

``` ts
setItems(items: IProduct[]): void
```

Сохраняет массив товаров.

``` ts
getItems(): IProduct[]
```

Возвращает массив товаров.

``` ts
getItem(id: string): IProduct | undefined
```

Возвращает товар по id.

``` ts
setPreview(item: IProduct): void
```

Сохраняет товар для предпросмотра.

``` ts
getPreview(): IProduct | null
```

Возвращает товар предпросмотра.

------------------------------------------------------------------------

### BasketModel

Класс модели корзины.

Отвечает за: - хранение товаров корзины; - добавление товаров; -
удаление товаров; - подсчёт общей стоимости; - очистку корзины.

#### Поля

``` ts
protected items: IProduct[];
```

#### Методы

``` ts
addItem(item: IProduct): void
```

Добавляет товар в корзину.

``` ts
removeItem(id: string): void
```

Удаляет товар из корзины по id.

``` ts
clear(): void
```

Очищает корзину.

``` ts
getItems(): IProduct[]
```

Возвращает товары корзины.

``` ts
getTotal(): number
```

Возвращает общую стоимость корзины.

``` ts
getCount(): number
```

Возвращает количество товаров в корзине.

``` ts
hasItem(id: string): boolean
```

Проверяет наличие товара в корзине.

------------------------------------------------------------------------

Отвечает за: - хранение данных покупателя; - изменение полей формы; -

#### Поля

``` ts

```

Возвращает данные покупателя.


Возвращает ошибки валидации формы.

``` ts

```

Очищает данные покупателя.

## Архитектура приложения

Проект построен по паттерну MVP (Model-View-Presenter).

### Model

Модели отвечают за хранение и обработку данных приложения.

### View

Компоненты интерфейса отвечают за отображение данных пользователю.

### Presenter

Связывает модели и отображение, обрабатывает пользовательские действия.

------------------------------------------------------------------------

## Классы представления (View)

### Card

Базовый класс отображения карточки товара. Отвечает за вывод
изображения, названия, категории, цены и описания товара. Используется
как общий родитель для различных шаблонов карточек.

### Basket

Отвечает за отображение содержимого корзины, списка выбранных товаров,
общей стоимости заказа и кнопки оформления.

### Form

Базовый класс для работы с формами приложения. Реализует общий
функционал обработки ввода данных, отображения ошибок валидации и
управления состоянием кнопки отправки.

### OrderForm

Наследуется от класса `Form`. Отвечает за отображение первого шага
оформления заказа: выбор способа оплаты и ввод адреса доставки.

### ContactsForm

Наследуется от класса `Form`. Отвечает за отображение второго шага
оформления заказа: ввод электронной почты и телефона покупателя.

### Modal

Компонент модального окна. Отвечает за открытие и закрытие модального
окна, отображение переданного содержимого и обработку действий
пользователя. Не является родительским классом для других компонентов.

### Page

Компонент главной страницы приложения. Отвечает за отображение каталога
товаров, управление счётчиком корзины и размещение основных элементов
интерфейса.

### Success

Компонент отображения успешного оформления заказа. Показывает информацию
об успешном заказе, сумму списанных синопсов и кнопку возврата к
каталогу.
