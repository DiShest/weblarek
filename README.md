## Типы данных

### IProduct

Интерфейс товара.

``` ts
interface IProduct {
    id: string;
    description: string;
    image: string;
    title: string;
    category: string;
    price: number | null;
}
```

**Описание полей:**

- `id` — уникальный идентификатор товара.
- `description` — описание товара, отображаемое в карточке и окне предпросмотра.
- `image` — путь к изображению товара, получаемый с сервера.
- `title` — название товара.
- `category` — категория, к которой относится товар.
- `price` — стоимость товара. Если значение равно `null`, товар недоступен для покупки.

------------------------------------------------------------------------

### IProductsResponse

Тип ответа сервера с массивом товаров.

``` ts
interface IProductsResponse {
    total: number;
    items: IProduct[];
}
```

**Описание полей:**

- `total` — общее количество товаров, полученных от сервера.
- `items` — массив объектов типа `IProduct`, содержащий список товаров каталога.

------------------------------------------------------------------------

### TPayment

Тип способа оплаты.

``` ts
type TPayment = 'card' | 'cash';
```

Тип определяет допустимые способы оплаты заказа:

- `card` — оплата банковской картой;
- `cash` — оплата при получении.
------------------------------------------------------------------------

### IBuyer

Интерфейс данных покупателя.

``` ts
interface IBuyer {
    payment: TPayment;
    address: string;
    email: string;
    phone: string;
}
```
**Описание полей:**

- `payment` — выбранный способ оплаты.
- `address` — адрес доставки, введённый пользователем.
- `email` — электронная почта покупателя.
- `phone` — контактный номер телефона покупателя.

------------------------------------------------------------------------

### IOrder

Интерфейс заказа.

``` ts
interface IOrder {
    items: string[];
    total: number;
    payment: TPayment;
    address: string;
    email: string;
    phone: string;
}
```
**Описание полей:**

- `payment` — выбранный пользователем способ оплаты заказа.
- `address` — адрес доставки заказа.
- `email` — адрес электронной почты покупателя.
- `phone` — номер телефона покупателя.
- `items` — массив идентификаторов товаров, входящих в заказ.
- `total` — итоговая стоимость заказа.
------------------------------------------------------------------------

### TOrderForm

Тип формы первого шага заказа.

``` ts
type TOrderForm = Pick<IOrder, 'payment' | 'address'>;
```
**Описание полей:**

- `payment` — выбранный пользователем способ оплаты заказа.
- `address` — адрес доставки, введённый пользователем.

Тип `TOrderForm` представляет собой часть интерфейса `IOrder`, используемую на первом этапе оформления заказа, где пользователь выбирает способ оплаты и указывает адрес доставки.
------------------------------------------------------------------------

### TContactsForm

Тип формы контактов покупателя.

``` ts
type TContactsForm = Pick<IOrder, 'email' | 'phone'>;
```
**Описание полей:**

- `email` — адрес электронной почты покупателя.
- `phone` — контактный номер телефона покупателя.

Тип `TContactsForm` содержит данные второго шага оформления заказа и используется для ввода контактной информации пользователя.
------------------------------------------------------------------------

### TFormErrors

Тип ошибок валидации формы.

``` ts
type TFormErrors = Partial<Record<keyof IBuyer, string>>;
```
**Описание:**

Тип `TFormErrors` хранит ошибки валидации полей формы покупателя.

**Описание полей:**

- `payment` — сообщение об ошибке, связанной с выбором способа оплаты.
- `address` — сообщение об ошибке поля адреса доставки.
- `email` — сообщение об ошибке поля электронной почты.
- `phone` — сообщение об ошибке поля телефона.

Тип построен на основе `IBuyer`, поэтому содержит только те поля, для которых может быть сформировано сообщение об ошибке валидации.
------------------------------------------------------------------------

### IOrderResponse

Тип ответа сервера после оформления заказа.

``` ts
interface IOrderResponse {
    id: string;
    total: number;
}
```
**Описание полей:**

- `id` — уникальный идентификатор успешно созданного заказа.
- `total` — итоговая сумма оформленного заказа.

## Классы моделей данных

### ProductsModel

Класс модели каталога товаров.

Отвечает за: - хранение массива товаров; - получение товара по id; -
хранение товара для предпросмотра.

#### Поля

``` ts
protected items: IProduct[];
protected preview: IProduct | null;
```

#### Методы

``` ts
setItems(items: IProduct[]): void
```

Сохраняет массив товаров.

``` ts
getItems(): IProduct[]
```

Возвращает массив товаров.

``` ts
getItem(id: string): IProduct | undefined
```

Возвращает товар по id.

``` ts
setPreview(item: IProduct): void
```

Сохраняет товар для предпросмотра.

``` ts
getPreview(): IProduct | null
```

Возвращает товар предпросмотра.

------------------------------------------------------------------------

### BasketModel

Класс модели корзины.

Отвечает за: - хранение товаров корзины; - добавление товаров; -
удаление товаров; - подсчёт общей стоимости; - очистку корзины.

#### Поля

``` ts
protected items: IProduct[];
```

#### Методы

``` ts
addItem(item: IProduct): void
```

Добавляет товар в корзину.

``` ts
removeItem(id: string): void
```

Удаляет товар из корзины по id.

``` ts
clear(): void
```

Очищает корзину.

``` ts
getItems(): IProduct[]
```

Возвращает товары корзины.

``` ts
getTotal(): number
```

Возвращает общую стоимость корзины.

``` ts
getCount(): number
```

Возвращает количество товаров в корзине.

``` ts
hasItem(id: string): boolean
```

Проверяет наличие товара в корзине.

------------------------------------------------------------------------

### BuyerModel

Класс модели покупателя.

Отвечает за: - хранение данных покупателя; - изменение полей формы; -
валидацию данных покупателя; - очистку данных формы.

#### Поля

``` ts
protected buyer: IBuyer;
```

#### Методы

``` ts
setField<K extends keyof IBuyer>(
    field: K,
    value: IBuyer[K]
): void
```

Устанавливает значение поля покупателя.

``` ts
setPayment(payment: TPayment): void
```

Устанавливает способ оплаты.

``` ts
getData(): IBuyer
```

Возвращает данные покупателя.

``` ts
validate(): TFormErrors
```

Возвращает ошибки валидации формы.

``` ts
clear(): void
```

Очищает данные покупателя.

## Архитектура приложения

Проект построен по паттерну MVP (Model-View-Presenter).

### Model

Модели отвечают за хранение и обработку данных приложения.

### View

Компоненты интерфейса отвечают за отображение данных пользователю.

### Presenter

Связывает модели и отображение, обрабатывает пользовательские действия.

## Классы представления (View)

### Card

Базовый класс отображения карточки товара. Используется как родительский класс для различных представлений карточек.

**Поля:**

- элементы DOM карточки товара (название, изображение, категория, цена и описание);
- контейнер карточки, используемый для отображения данных.

**Конструктор:**

Принимает HTML-элемент карточки и инициализирует ссылки на необходимые DOM-элементы.

**Методы:**

- `render()` — отображает данные товара;
- сеттеры изменяют название, изображение, категорию, цену и описание товара.

### CatalogCard

Наследуется от класса `Card`. Используется для отображения товара в каталоге.

**Поля:**

- элементы карточки товара;
- обработчик выбора товара.

**Конструктор:**

Принимает HTML-элемент карточки и объект событий.

**Методы:**

- отображает данные товара;
- генерирует событие открытия предпросмотра при выборе карточки.

### PreviewCard

Наследуется от класса `Card`. Используется для отображения подробной информации о товаре в модальном окне.

**Поля:**

- элементы карточки;
- кнопка добавления товара в корзину.

**Конструктор:**

Принимает HTML-элемент карточки и объект событий.

**Методы:**

- отображает информацию о товаре;
- изменяет состояние кнопки покупки;
- генерирует событие добавления товара в корзину.

### Basket

Отвечает за отображение содержимого корзины, списка выбранных товаров, общей стоимости заказа и кнопки оформления.

**Поля:**

- список товаров корзины;
- элемент итоговой стоимости;
- кнопка оформления заказа.

**Конструктор:**

Принимает контейнер корзины и объект событий.

**Методы:**

- `render()` — обновляет содержимое корзины и отображает актуальную стоимость и список товаров.

### BasketItem

Компонент отображения отдельного товара в корзине.

**Поля:**

- название товара;
- цена товара;
- кнопка удаления.

**Конструктор:**

Принимает HTML-элемент строки корзины и объект событий.

**Методы:**

- отображает данные товара;
- генерирует событие удаления товара из корзины.

### Form

Базовый класс для работы с формами приложения.

**Поля:**

- элементы формы;
- кнопка отправки;
- контейнер отображения ошибок.

**Конструктор:**

Принимает HTML-форму и объект событий.

**Методы:**

- `render()` — обновляет состояние формы;
- отображает ошибки валидации;
- управляет состоянием кнопки отправки.

### OrderForm

Наследуется от класса `Form`. Отвечает за первый шаг оформления заказа.

**Поля:**

- кнопки выбора способа оплаты;
- поле ввода адреса доставки.

**Конструктор:**

Принимает HTML-элемент формы и объект событий.

**Методы:**

- отображает выбранный способ оплаты;
- обновляет адрес доставки;
- изменяет состояние формы в соответствии с данными модели.

### ContactsForm

Наследуется от класса `Form`. Отвечает за второй шаг оформления заказа.

**Поля:**

- поле электронной почты;
- поле телефона.

**Конструктор:**

Принимает HTML-элемент формы и объект событий.

**Методы:**

- отображает введённые контактные данные;
- показывает ошибки валидации;
- обновляет состояние формы.

### Modal

Компонент модального окна.

**Поля:**

- контейнер модального окна;
- область отображения содержимого;
- кнопка закрытия.

**Конструктор:**

Принимает HTML-элемент модального окна и объект событий.

**Методы:**

- `open()` — открывает модальное окно;
- `close()` — закрывает модальное окно;
- `render()` — отображает переданный контент внутри модального окна.

### Page

Компонент главной страницы приложения.

**Поля:**

- контейнер каталога;
- кнопка корзины;
- счётчик товаров в корзине.

**Конструктор:**

Принимает корневой элемент страницы и объект событий.

**Методы:**

- обновляет каталог товаров;
- изменяет счётчик корзины;
- управляет отображением элементов страницы.

### Success

Компонент отображения успешного оформления заказа.

**Поля:**

- текст с итоговой суммой;
- кнопка возврата к каталогу.

**Конструктор:**

Принимает HTML-элемент шаблона и объект событий.

**Методы:**

- `render()` — отображает сумму успешно оформленного заказа;
- обрабатывает нажатие кнопки возврата.

## События Presenter

- `catalog:changed` — обновляет отображение каталога товаров после изменения модели.
- `product:select` — открывает предпросмотр выбранного товара.
- `preview:changed` — обновляет содержимое окна предпросмотра.
- `preview:buy` — добавляет выбранный товар в корзину.
- `basket:changed` — обновляет содержимое корзины и итоговую стоимость.
- `basket:open` — открывает модальное окно корзины.
- `basket:remove` — удаляет товар из корзины.
- `order:open` — открывает форму оформления заказа.
- `order.address:change` — изменяет адрес доставки в модели покупателя.
- `order.payment:change` — изменяет выбранный способ оплаты.
- `order:submit` — завершает первый шаг оформления и открывает форму контактов.
- `contacts.email:change` — обновляет адрес электронной почты покупателя.
- `contacts.phone:change` — обновляет номер телефона покупателя.
- `contacts:submit` — отправляет данные заказа на сервер.
- `buyer:changed` — синхронизирует состояние форм после изменения модели покупателя.
- `success:close` — закрывает окно успешного оформления заказа и возвращает пользователя к каталогу.
